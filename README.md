# ⚔️ KnightByte

**A medieval adventure trapped inside a digital world.**

KnightByte is a small Pygame game created for the **Hack Club Stardance Challenge 2026**.

You play as a knight who finds himself trapped in a strange, technology-filled world. Explore the village, meet its inhabitants, train your character, and uncover what is really going on.

## 🎮 About the Game

KnightByte combines a medieval fantasy setting with a weird digital/technology theme.

The game is currently a **work in progress**, with the main focus being exploration, dialogue, progression, and building the world of KnightByte.

### Current features

* 🏰 Medieval village to explore
* 💬 Dialogue system
* ⚔️ Knight progression and training
* 📈 Player stats and progression
* 🎵 Custom music and sound effects
* 💾 Save data
* 🖥️ Custom Pygame interface
* 🤖 A strange mix of medieval fantasy and technology

## 🛠️ Built With

* **Python**
* **Pygame**
* **NumPy**
* **JSON** for save data
* **GitHub** for version control

## 🚀 Running the Game

Clone or download this repository and run:

```bash
python main.py
```

Make sure the required Python packages are installed:

```bash
pip install pygame numpy
```
